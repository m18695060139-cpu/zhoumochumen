## 新增一场活动时

在对应活动线文件夹里新建 `YYYY-MM-DD_活动名.md`，可以复制 [活动记录模板.md](活动记录模板.md)，然后在 [活动时间线.md](活动时间线.md) 里加一行。物料多的活动（比如趣味主题活动线）改成建文件夹 `YYYY-MM-DD_活动名/`，方案、问卷、物料都放里面。发出去的帖子存到 `06_发布内容/`，方案和发布稿两边互相加链接。
